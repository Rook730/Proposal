Kept Spec Proposal Builder for Windows.

**Download** `KeptSpec Proposal Builder.exe` and run it. No Python needed.

- First start takes 10 to 20 seconds while the app unpacks; later starts are similar.
- Windows may show "Windows protected your PC" because the app is not code-signed: click **More info**, then **Run anyway**.
- Your data folder setting carries over from earlier versions (it is stored in `%APPDATA%\KeptSpecProposal\config.json`).
- If the single file starts slowly or antivirus objects to it, use `KeptSpec-Proposal-Builder-folder.zip`: unzip it anywhere and run the `.exe` inside the folder.

To update later, download the new `.exe` and replace the old one. Your data is not stored next to the program, so nothing is lost.
