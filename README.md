# Proposal

Proposal builder for Kept Spec Advisors (Convenient Enterprises LLC). Standalone Windows application that replaces the Excel proposal workflow: catalog, proposals with revisions and alternates, change orders, and whole-project reconciliation, exported to PDF.

Status: requirements phase. See [docs/requirements.md](docs/requirements.md).

Planned stack: Python 3.12, NiceGUI (native window), Typst for PDF, JSON file storage, PyInstaller .exe.
